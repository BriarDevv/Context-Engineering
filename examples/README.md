# Examples

Synthetic repos showing the standard applied end-to-end. Not real projects —
the code files are minimal stubs; the context files are the point. They also
serve as fixtures for tooling that checks the standard.

| Example | Shows |
|---|---|
| [`nextjs-ecommerce/`](nextjs-ecommerce/) | Single-app repo, personal profile: 4-block CLAUDE.md, minimal AGENTS.md, docs index, one ADR, one rich-reference spec with a Mermaid state machine |

Note: in a real `context-init` run, Commands are verified by executing them
and Gotchas come from interviewing the owner. Here both are simulated.
